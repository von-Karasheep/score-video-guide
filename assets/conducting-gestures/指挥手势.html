三拍

一帧里的棒尖、手与指挥棒怎样画

这套动画用 Python 和 Pillow 逐帧绘制。每帧读入拍号、手势、当前挥次和已经走过的比例，先算出棒尖，再由棒尖带动整只手。绘图用 394 × 116 的逻辑画布，左上角是原点，向右为 x 增大，向下为 y 增大。按两倍尺寸输出 788 × 232 像素；贝九末乐章的 4K 成片将整张卡贴在 (1636, 252)。

  1. 先画卡面和路标。铺浅绿圆角底，左栏用 MiSans 写谱面拍号与音符单位，中栏写当前拍位。右边先画完整的灰绿导向弧，再画编号圈。一小节一挥只在低处画一个实心落点。切换到后半拍时，慢三拍的三个主拍圈仍留在原处。
  2. 在曲线上取棒尖的位置。每段三次贝塞尔曲线按参数从 0 到 1 等分成 60 段，存下 61 个点。取当前这一下已经走过的比例 p，用 60p 找到相邻两个点，按小数部分在两点间插值。棒尖后方沿当前弧段取最多 12 个采样间隔和当前小段，画出深绿色短尾迹。
  3. 让手握住棒。先确定棒尖 (x, y)，再把手形原点定在 (x + 26, max(14, y − 39))。从棒尖向手形原点右 2、上 2 的位置画深色棒身；在棒尖画白边绿点，然后叠上米色手形的外轮廓、两道手指折线和深绿袖口。手与袖口随同一原点平移，上限使抬手时仍能看见袖口。
展开建线参数与颜色，复画同一条弧

普通二、三、四拍的每一段从 A=(x, y) 到下一落点 B=(u, v)，两个控制点依次为 (x+4, y−23) 和 (u−16, v−25)。浅色导线和棒尖共用这条曲线。下列两种动作有自己的回弹。

  • 整小节一挥。上提的四个点依次为 (284,92)、(271,66)、(313,30)、(306,17)。回落依次为 (306,17)、(301,37)、(291,82)、(284,92)。先用全段时间的 53% 走完第一条，再用 47% 走完第二条。
  • 慢三拍分拍。在每个主落点 A 的右 8、上 5 设分拍点 M。A → M 的控制点为 (x−4, y−22)、(x+8, y−20)；M → B 的控制点为 (x+8, y−29)、(u−15, v−22)。每半拍都取一段完整曲线。浅色背景仍画三条主拍弧线。

怎样让每一拍跟上现场

  1. 选拍型，记落点。左栏保留总谱拍号，按指挥实际给出的主拍或分拍选择母版。逐帧看清楚的右手或棒尖，在转折处结合乐队起音确认第几小节、第几拍，把落点换算到成片时间。分别标记看得见的落点、仅从声音核实的进入和推算的中间拍。
  2. 在两个锚点之间调速。沿已经对齐的总谱与演奏时钟，按各拍在这段演奏中的相对位置分配到两个已知落点之间。遇到明显换速或再起，加一个可核对的锚点。每一帧按当前拍的实际起止时间沿原轨迹取位置。
  3. 弱起、延长和换拍。弱起从实际挥到的那一下或半途接入。延长时把一拍拆开，把停住这一行的起止进度写成同一个值，直到再起才继续。换拍型时在实际第一下切换；末次收拍按现场余响保留静止姿势。表中的 mode 控制文字，phase_from 和 phase_to 决定棒尖是否移动。

在每个区间 [start, end) 内，先算 f = (t − start) / (end − start)，再算 p = phase_from + f × (phase_to − phase_from)。调用 frame(meter, pattern, stroke, p, mode)。stroke 从 0 数起；到了区间末端，改读下一行。正常一挥的 p 从 0 到 1。

新片用哪一版手势

先按指挥实际挥出的拍数和分拍方式选上面的一条路径，把分组、起止时间、起始挥次和停顿写入这场演出的逐拍表。新片沿用同一套手形、落点与轨迹。遇到新的挥法，先做完整一小节，记录每一下从哪落到哪、怎样回弹，连同轨迹文件与循环预览一起登记。每部成片归档所用母版版本、逐拍拍点，以及从成片裁下的每种拍号与挥法的无声片段。

贝多芬系列的其余版式

  1. 演出与总谱。用节目单或发行资料核实日期、地点、乐团、指挥、合唱团和独唱者。确认总谱版本，按现场演奏顺序展开反复、跳房子和弱起。将总谱小节、现场时间和成片时间对应起来。
  2. 片头与正文。片头约三秒交代作品、乐章和演出，再用约三秒给出曲式。按 1920 × 1080 排版，导出为 3840 × 2160、30 帧/秒。左栏显示一个完整谱表系统，保留谱号、调号和声部名。游标从第一个发声音符开始走。
  3. 记号、主题和调性。砖红框圈出谱上正在解释的记号，左侧用中文说明。主题用固定字母和颜色，右侧谱例与左侧对应乐句同色。调性说明写出可听见的依据，例如低音走向或终止式。
  4. 演出小窗与唱词。在小窗左缘下方用 MiSans 写声部、中文姓名和括号内的外文名。先按实唱核对原文，再在顶部中央框内上排用霞鹜文楷写中文、下排写这场演出实际唱的原文。待唱部分用浅色，唱到的原词或音节与对应中文词组加深。纯器乐段收起歌词框。
  5. 时间轴与声音。用上下两层显示曲式和主题，段宽按实演时长分配，当前段从左向右填充。原片时间码放工程索引。优先保留可核实的同场无损音轨，记录音轨格式和来源。
  6. 分段 TXT。每部作品、同场演出共用一份 UTF-8 纯文本。首行写“【乐谱同步+分段与动机提示版】作曲家《曲名》-指挥+乐团英文简称@年份”。按“第一乐章：”等标题分组，每乐章最多十行时间标记，首条为“00:00 引言；制作说明；总览”。每个时间后接一个半角空格和段名，用“呈示部：主部”等全角标点。按实际成片取时间；终乐章有宣叙、变奏或赋格时写实际曲式。做完新乐章后更新同一份 TXT。
  7. 交付与复核。看成片里的起拍、换速、换拍、翻页、声部进入和收束，听到最后的余响，检查完整解码。同一作品各乐章共用一套封面，分别排 16:9 和 4:3 两张图。
